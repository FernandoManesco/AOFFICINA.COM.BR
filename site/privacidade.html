Política de privacidade

Site aofficina.com.br · IA Process Automation · Rio Claro/SP

Este site

Este site não usa cookies de rastreamento nem formulários que gravem dados. O formulário de contato apenas monta uma mensagem que você envia pelo seu próprio WhatsApp; nada é armazenado em nossos servidores a partir dele. Fontes tipográficas são carregadas do Google Fonts e algumas fotos ilustrativas do Unsplash — esses serviços podem registrar o seu endereço IP conforme as políticas deles.

O sistema aOfficina

O aOfficina é um software de gestão licenciado para oficinas mecânicas. Os dados cadastrados no sistema (clientes, veículos, ordens de serviço, pagamentos) pertencem à oficina licenciada, que é a controladora desses dados nos termos da Lei nº 13.709/2018 (LGPD). Quando o sistema está hospedado em nossos servidores, a IA Process Automation atua como operadora: processa os dados exclusivamente para prestar o serviço contratado, em banco de dados exclusivo de cada oficina, com cópias de segurança diárias e acesso restrito por credenciais individuais.

As funções de inteligência artificial enviam ao provedor de IA apenas o texto do campo em uso (por exemplo, o diagnóstico) para correção ou pesquisa, sem dados de identificação do cliente final. A transcrição de voz pode ser processada no próprio servidor da oficina.

Seus direitos

Titulares de dados podem solicitar confirmação, acesso, correção, anonimização ou eliminação de dados pessoais junto à oficina controladora. Dúvidas sobre o tratamento realizado pela IA Process Automation podem ser dirigidas ao nosso encarregado (DPO) pelo WhatsApp (19) 99608-5277.
